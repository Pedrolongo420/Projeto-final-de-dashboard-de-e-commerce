# \# Dashboard de Análise de E-commerce

# 

# Projeto desenvolvido em Python com o objetivo de criar uma aplicação interativa utilizando Dash e Plotly para visualização de dados de e-commerce.

# 

# \## Objetivo

# 

# A aplicação permite visualizar os principais indicadores do conjunto de dados sem a necessidade de interação direta com o código Python.

# 

# \## Visualizações desenvolvidas

# 

# \- Histograma de preços

# \- Gráfico de dispersão entre preço e nota

# \- Mapa de calor de correlações

# \- Gráfico de barras das principais marcas

# \- Gráfico de pizza por gênero

# \- Gráfico de densidade das notas

# \- Gráfico de regressão entre número de avaliações e quantidade vendida

# 

# \## Tecnologias utilizadas

# 

# \- Python

# \- Pandas

# \- NumPy

# \- Plotly

# \- Dash

# \- Scikit-learn

# 

# \## Arquivos do projeto

# 

# \- `app.ipynb`: notebook principal contendo a análise e a aplicação Dash

# \- `ecommerce\_estatistica.csv`: base de dados utilizada

# \- `requirements.txt`: dependências necessárias para execução do projeto
